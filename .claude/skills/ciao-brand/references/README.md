# Design references

Frames exported from the Figma file. **Look at these before changing a screen** —
the written rules in `SKILL.md` carry colours and radii accurately and carry
composition not at all, which is how a brand pass once shipped with the tokens
applied and none of the layouts.

## What is here

The five mobile **dark** frames. Ciao is **light first** — dark is a supported
theme, not the default — so these show the right composition in the wrong
default. Read them for layout, hierarchy and component anatomy; read `SKILL.md`
for which colour each part takes in light.
